# 基于 Primary Frequency Regulation Monitor 现有问题与改进方向

背景：Primary Frequency Regulation Monitor 作为工业级遥测/通信/记录看板（Qt/QML + C++），关注高吞吐、长时间运行下的稳定性、可观测性、持久化和易用性。

## 现有问题（代码层面）
- UI 刷新率设置键不一致：读取 `uiRefreshRate`、写入 `uiTimerHz`，重启后自定义 FPS 不生效（`Misc/TimerEvents.cpp`）。
- 帧队列/导出队列忽略入队失败：`FrameReader` 和 CSV 导出队列满时静默丢帧，无计数/告警（`FrameReader::processData`、`CSV::Export::hotpathTxFrame`）。
- 帧解析线程默认关闭（`thrFrameExtr` 默认 false），高负载时帧切分落在 UI 线程，易卡顿。
- Dashboard 对模型不匹配过度反应：缺失 dataset UID 会直接断开设备/关闭 CSV/MQTT，而非柔性处理（`Dashboard::updateDashboardData`）。
- 窗口布局几何不持久化，只保存壁纸；重启/切换项目需要重新摆放浮窗（`WindowManager`）。
- 持久化与回放能力弱：仅有 CSV 导出，无带 schema/版本/校验的滚动二进制日志。
- 连接断开后的通用自动重连缺失：串口有 `autoReconnect` 开关，网络/其他总线无统一重连或心跳检测。
- 缺少系统健康监控：无看门狗检测 UI 线程冻结或数据流中断。
- 单帧处理潜在瓶颈：`Manager::onReadyRead` 逐帧调用 `FrameBuilder::hotpathRxFrame`，高吞吐场景需验证是否成为热点。
- 无数据分析和报警能力：缺少统计分析（均值/方差/峰值）、阈值报警和异常检测。

## 改进建议
- 可靠性与线程：
  - 默认开启帧解析工作线程，设置中提供开关便于调试。
  - 为帧/导出队列增加背压策略（丢最新/丢最旧/阻塞可选）和容量指标。
  - 校验/解析错误使用限频警告而非致命断链，提供"跳过坏帧"模式。
  - 实现统一自动重连：网络/BLE 等总线补齐重连，指数退避（1s→2s→4s，最大60s），可配置重试次数；串口沿用现有 `autoReconnect`。
  - 增加心跳检测：周期性发送心跳包，超时触发重连。
  - 添加看门狗：监控 UI 线程响应性和数据流活跃度，异常时记录堆栈并告警。
- 可观测性：
  - 记录丢帧数、队列水位、解析错误、FPS、写入失败；在状态面板和日志展示。
  - 会话健康摘要（运行时长、流量、丢帧、重连次数）支持按需导出。
- 持久化与存储：
  - 按项目/设备配置持久化窗口/任务栏布局（位置、尺寸、z 序、自动布局标志）。
  - 增加二进制滚动日志（如 protobuf/CBOR + 校验）并按时间/大小轮转，可选回放器直喂 FrameBuilder。
  - CSV 导出增加清单（schema hash、时区、分隔符）并支持断点续写安全。
  - 可选集成时序数据库（QuestDB/InfluxDB）：支持高吞吐写入、数据降采样和灵活查询。
  - 实现分级存储：热数据（内存+SSD）、温数据（压缩）、冷数据（归档）。
- 性能优化（需要压测验证）：
  - 批量帧处理：`Manager::onReadyRead` 支持批量（如 100 帧/批）下推到 `FrameBuilder`，减少函数调用开销。
  - 优先级队列：关键数据（报警、控制指令）优先处理，普通数据可延迟。
  - 内存优化：引入内存池复用 Frame 对象，减少频繁分配/释放；探索零拷贝传输（QSharedPointer）。
- 数据分析与报警：
  - 实时统计：滑动窗口计算均值、方差、峰值、百分位数（P50/P90/P95/P99）。
  - 阈值报警：支持配置上下限、偏离率，触发时高亮显示并记录日志。
  - 异常检测：基于3σ原则或机器学习算法检测数据突变。
- 工业场景 UX：
  - 引入"采集会话"：开始/结束可填操作员备注，生成目录含数据与清单。
  - 波形/FFT 支持暂停、拖动、标记与书签，便于事后分析。
  - 刷新率设置使用一致键并校验，提供 15/30/60/120/240 Hz 预设与配置文件默认值。
- 架构与测试：
  - 用会话级对象替代全局单例，支持多设备并行或无界面服务模式。
  - 为 FrameReader（分包、校验、错帧）和 FrameBuilder 模式添加单测/模糊测试，CSV 写入做 golden 测试。
  - 提供无 QML 的最小 headless runner，在 CI 中验证数据链路与吞吐。
  - 增加压力测试：模拟高并发连接（100+）和高吞吐（10k+帧/秒），验证长时间运行稳定性（24小时+）。

## 快速收益（低风险）
- 统一刷新率设置键，必要时迁移旧值。
- 默认将 `thrFrameExtr` 设为 true 并在设置说明。
- 入队失败时统计并记录丢帧（帧队列 + CSV 队列），暴露计数给 QML 做状态提示。
- Dashboard 遇到 UID 不匹配时柔性降级：跳过坏帧+告警，保持连接。
- 将窗口布局（位置、尺寸、z 序）按项目/配置存入 QSettings。
- 在 IO::Manager/网络驱动中添加简单的自动重连（固定间隔 3 秒，最多重试 10 次），串口继续使用现有 `autoReconnect`。
- 增加数据流活跃度检测：10秒无数据时在状态栏显示警告。
- 为关键 dataset 添加简单阈值报警配置（上下限），在项目 JSON 中定义。
